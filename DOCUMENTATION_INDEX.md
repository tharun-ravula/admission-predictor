## 🔧 Customization Guide

### Change App Colors
Edit `.streamlit/config.toml`:
```toml
[theme]
primaryColor = "#FF6B6B"      # Change this color
```

### Add New Features
Edit `app.py`:
```python
# Add new input fields in Prediction section
new_feature = st.slider("New Feature", 0, 100, 50)
```

### Modify Model
Edit `model.py`:
```python
# Change algorithm or parameters
classifier = LogisticRegression(max_iter=5000)
```

## 📱 Deployment Options

### Option 1: Run Locally (Current Setup)
```bash
streamlit run app.py
```
- Access at: http://localhost:8501
- Best for: Development & testing

### Option 2: Deploy to Streamlit Cloud (Free)
1. Push code to GitHub
2. Sign up at https://streamlit.io/cloud
3. Deploy in 2 clicks
4. Share public URL with others

### Option 3: Docker Container
```dockerfile
FROM python:3.9
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
CMD ["streamlit", "run", "app.py"]
```

## 🐛 Common Issues & Solutions

| Problem | Solution |
|---------|----------|
| `ModuleNotFoundError` | Run `pip install -r requirements.txt` |
| `Model not found` | Run `python model.py` to train |
| `Port already in use` | Run `streamlit run app.py --server.port 8502` |
| `Slow predictions` | Restart: `Ctrl+C` then `streamlit run app.py` |
| `Import errors` | Update packages: `pip install --upgrade -r requirements.txt` |

## 📊 Dataset Information

**Admission.csv** contains:
- **400 records** of student admission data
- **7 columns**: admit, gre, gpa, ses, Gender_Male, Race, rank
- **Target**: admit (0=rejected, 1=admitted)
- **Model Accuracy**: ~87%
